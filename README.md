# ♻️ RecycleNow-Android

Aplicación móvil nativa Android orientada a fomentar el reciclaje y la cultura ambiental. Los usuarios pueden encontrar puntos de reciclaje en un mapa, acumular y canjear puntos por sus acciones ecológicas, y compartir sus manualidades con la comunidad.

---

## 📱 Características principales

- **Autenticación** — registro e inicio de sesión de usuarios con Firebase Authentication
- **Mapa de puntos de reciclaje** — visualización de puntos de reciclaje cercanos en mapa interactivo
- **Sistema de puntos** — acumulación de puntos por actividades de reciclaje
- **Canje de puntos** — redención de puntos acumulados por recompensas
- **Publicación de manualidades** — los usuarios comparten sus creaciones con materiales reciclados
- **Base de datos en tiempo real** — información sincronizada con Firebase

---

## 🛠️ Tecnologías utilizadas

| Categoría | Tecnología |
|---|---|
| Lenguaje | Java |
| UI | XML, RecyclerView, Fragments |
| Autenticación | Firebase Authentication |
| Base de datos | Firebase Realtime Database |
| Almacenamiento | Firebase Storage |
| Mapas | Google Maps SDK |
| IDE | Android Studio |
| Control de versiones | Git, GitHub |

## 🚀 Instalación

```bash
# Clonar el repositorio
git clone https://github.com/AndersonZamora/RecycleNow-Android.git

# Abrir en Android Studio
# File → Open → seleccionar la carpeta del proyecto

# Ejecutar en dispositivo o emulador
# Run → Run 'app'
```

> ⚠️ Requiere configurar un proyecto Firebase y agregar el archivo `google-services.json` en la carpeta `/app`.
> ⚠️ Requiere una API Key de Google Maps configurada en el `AndroidManifest.xml`.

---

## 📋 Requisitos

- Android 6.0 (API 23) o superior
- Conexión a internet
- GPS / Ubicación habilitada (para el mapa)
- Cuenta Firebase configurada
